## Search and language foundations

**Egothor v1–v3 (1998–2018)** was an open-source Java full-text search engine and the original home of the learned, language-independent stemming work, later extending into experimental data systems. The current portfolio returns to these two strands separately: [EGOTHOR v4](egothor-v4.md) explores regulated search, while [Radixor](radixor.md) revisits the Egothor/Stempel language-processing lineage.

## Distributed platforms and data systems

**J5M (2007–2015)** was a lightweight Java distributed application platform and coordination infrastructure with service discovery, lifecycle control and hot-spare object support.

**Bobo (2012–2014)** grew from the Egothor search infrastructure into a distributed crawler and virtual-entity platform.

**Q!D / Egothor3 (2015–2022)** was an experimental database system on J5M, investigating alternative large-data processing models within the Egothor3 data-platform research direction.

**Cyclone (2016–2018)** addressed a different part of the data pipeline: high-capacity distributed crawling and modular analysis of Facebook Graph API and RSS data.

**BOREI (Historical)** was a Java EE / J5M service platform with REST and WADL-facing interfaces, listed on LinkedIn.

## Networks, sensors and application services

**Galeo (2013–2014)** investigated IP geolocation through network-path measurements, heterogeneous propagation assumptions and latency-derived inference. Its focus was inference from network behaviour rather than an application-level location service.

**SNOG (2014–2015)**, the Sensor Network Open Gateway, integrated sensors, mobile clients, external services and user interfaces through a REST API.

**RaSPEL (2017–2018)** was a Java EE bridge/controller between LoRaWAN networks and RESTful business services.

**SafetyCare (2016–2020)** applied GPS/GSM capabilities to a personal-safety assistance application with location reporting and BTS lookup.
