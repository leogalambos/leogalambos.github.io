## Research direction

The core research problem is **authorization-aware information retrieval**: matching content is insufficient if the result should not be disclosed to the requesting user. The public concept encompasses clearance, classification, integrity, compartments and conflict boundaries, aligned with deterministic top-K retrieval.

This is a **private beta**; a public open-source release is planned. No publicly linked peer-reviewed manuscript is claimed here. For public status, consult the [project overview](https://www.egothor.org/projects/egothor-v4/).

## Continuity

The project revives the Egothor search-engine line first developed in 1998. Its current design targets information-governance constraints not central to the original engine. For the earlier Java full-text search and stemming work, see the [historical portfolio](heritage.md).
