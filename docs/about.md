## Teaching and academia

My university teaching has spanned operating systems, programming, databases, networks and distributed data processing. The course descriptions below condense historical teaching material; the technology names describe the syllabus rather than current course availability.

### Charles University — Faculty of Mathematics and Physics

**Unix Administration / Linux Administration for Developers (NSWI106)** covered the concepts and administration tools needed to operate Linux infrastructure for development, testing and core network services. Its topics included:

- Installation and storage: LVM, ZFS and RAID; backup and snapshots.
- Service and access administration: `systemd`, users, SELinux, OpenLDAP, SSSD/PAM and Kerberos.
- Networks and services: packet analysis with `tcpdump`, firewalls and NAT, `firewalld`, BIND, NFS, Postfix and Nginx.
- Trust infrastructure: PKI, OCSP and ACME.
- Development infrastructure: containers, virtualization and CI, including Docker/LXC and libvirt.

**Advanced Big Data Technologies (NDBI041)** combined theoretical foundations with hands-on work on large datasets. Topics included Hadoop, data-processing operations, HBase, Hive, Pig, Giraph and alternative processing approaches. Students completed their own data-oriented project.

### Czech Technical University in Prague — Faculty of Transportation Sciences

**Advanced C++ Programming** addressed object-oriented and generic programming, resource management, inheritance and polymorphism, templates, containers, iterators and algorithms. It also covered exception safety, portability and interaction with the operating system.

**Advanced Database Technologies** followed database architecture from conceptual design to physical storage: relational modelling, SQL and relational algebra, file and index organisation, B+ trees and hashing, buffer management and query optimisation. Further topics included System R principles, transactions, recovery, concurrency, and parallel and distributed databases.

**Computer Networks** connected Internet fundamentals with security: Ethernet, IP, TCP, UDP and ARP; DNS and DNSSEC; HTTP and mail protocols; routing, NAT, firewalls and proxies. Practical discussion included spoofing, denial-of-service patterns, session attacks and web-application weaknesses.

**Advanced Java Programming** used a project-based assessment model.
